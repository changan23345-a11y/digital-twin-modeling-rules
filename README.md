# 数字孪生建筑模型制作规则

用于指导 AI 使用 Blender，从图纸、参考照片和已有模型制作适合数字孪生网页实时渲染的建筑模型。

## 完整规则

请阅读并执行 [MODELING_RULES.md](./MODELING_RULES.md) 中的全部九条规则。

- 第一至第八条：资料分析、分阶段建模、确认、PBR 材质与 AO、源工程重开验收，以及按本轮范围启用的网页优化和 GLB 验证。
- 第九条：针对当前建筑确认实际场景、目标视觉效果、压缩质量和输出标准。
- 不直接套用上一项目的尺寸、配色或文件大小上限。
- 阶段之间由用户确认，已经授权的本阶段修改直接完成。

## 下一个项目怎么用

将以下指令发给能访问 GitHub 和建模环境的 AI 助手，同时提供新项目图纸、参考图片、已有模型或文件路径：

> 请读取 https://github.com/changan23345-a11y/digital-twin-modeling-rules 仓库中的 README.md 和 MODELING_RULES.md，并按完整规则执行本次数字孪生建筑模型制作。先查看我提供的资料，按第九条记录本轮交付物、资料依据、目标效果和验收方式。室内项目写明分组及关键通行路线。只交 Blender 工程时按源工程要求验收，进入网页交付时再确认压缩与导出要求。按第一至第八条中适用的阶段制作，每阶段确认后继续。不要沿用其他项目的尺寸、配色或大小限制。请先说明是否成功读取完整规则。

只发送链接可能被理解为普通参考，建议同时明确要求“读取并按规则执行”。仓库私有时，需要登录或提供仓库访问授权。无法读取时，可直接上传 MODELING_RULES.md 文件，不应声称已经读取或按未读取的规则执行。

## 下载到本地

可在 GitHub 仓库页面使用 Code → Download ZIP 下载，或使用 Git：

```sh
git clone https://github.com/changan23345-a11y/digital-twin-modeling-rules.git
```

已经克隆的仓库可在其文件夹内更新：

```sh
git pull
```
